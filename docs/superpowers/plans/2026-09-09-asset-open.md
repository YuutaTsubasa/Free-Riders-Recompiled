# Native read-only asset open implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development with separate spec and quality review. If the live agent limit prevents a fresh worker, reuse a worker that has not implemented this component.

**Goal:** The original game's NtCreateFile opens its actual extracted basic shader asset and retains a real native file object, then continues to the next original dependency.

**Architecture:** Windows AssetFiles owns a mounted root and read-only native handles. GuestFiles validates the verified Xbox ABI and publishes checked BE outputs only after a real open. The diagnostic accepts an explicit optional asset-root argument; an absent mount stops at the first supported file request. The existing image/header validation remains prior to game execution. No success stub or replacement higher-level game loader.

**Tech Stack:** C++20, Windows file APIs, checked GuestMemory, native fixture tests and real original-entry regression.
