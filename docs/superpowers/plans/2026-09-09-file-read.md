**Goal:** The original NtReadFile fills the game's allocated shader buffer with actual bytes from its retained native file, then resumes the original loader.

**Architecture:** AssetFiles reads synchronously from its owned HANDLE into a temporary byte vector, retaining the actual native file position. GuestFiles preflights guest output ranges and request semantics, copies exactly transferred bytes through checked GuestMemory stores and writes the BE IO result. The exact import logs the hash of bytes actually copied into guest memory.
