Goal: implement the missing instruction at 0x82211D68 and execute the containing original function, without deleting unsupported events or patching guest control flow.

Evidence: IBM describes SUBFZE as ones-complement RA plus old CA, updating CA; plain form leaves CR and overflow fields unchanged. Pinned Xenia ppc_emit_alu.cc520-535 computes the full 64-bit result, and AddWithCarryDidCarry at34-40 calculates carry using low32 operands. Thus for the diagnostic's existing 32-bit carry model, result is (~RA64 + oldCA) modulo2^64, newCA is oldCA && low32(RA)==0. Only plain subfze is in scope; record/OE forms remain unsupported. Actual caller has RA=-1 and consumes a preceding subfc carry.
