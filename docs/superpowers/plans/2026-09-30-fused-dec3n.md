# Fused DEC3N vertex conversion

Goal: reduce the measured CPU conversion cost while preserving every output
byte, vertex attribute location, shader ABI, drawing and guest timing.

Evidence: vertex-costs-1 measured 0.661 ms word swap and 0.705 ms DEC3N expansion
per late race frame. The existing expanded path swaps into scratch, then copies
each vertex to its final GPU upload allocation and appends expanded attributes.
An isolated fused prototype matches the old output. Dynamic-stride fusion can
regress small vertices; fixed-stride dispatch removes that prototype regression.
These are warm microbenchmarks, not game/handheld FPS evidence.

Implementation: a checked native_formats helper reads big-endian source once
per vertex and writes the converted base vertex plus appended SNORM16 values
directly to the destination, without reading write-combined output. Specialize
common strides; retain a scalar byte-equivalent path for odd strides/offsets.
Malformed spans/offsets return false before writing. Input/output are disjoint.
Use the existing SSSE3 / NEON / scalar swap paths, no new ISA requirement.

Tests first: independent whole-source scalar word swap and legacy rounding,
all 1024 component patterns, specialized/generic and odd strides, multiple or
unaligned attribute offsets, unaligned source/destination, destination guards,
immutable source, empty input and invalid ranges rejected without writes.
Then compile, inspect and benchmark the real helper; preserve the old runtime.

Integrate only into the DEC3N branch. Keep ordinary vertices on swap_words_into.
Metrics report fused work as repack time; swapped source-byte accounting still
includes both paths so cached+swapped remains total. Compare total swap+repack
cost, not either timer alone. Verify the same actual race, logs and screenshots.
No interaction with Claude's scheduling files or published packages.

## Outcome: experimental code restored out of the branch

All byte/bounds tests and Android ARM64 compilation passed, but three full
11,500-present race captures did not establish a stable performance benefit.
The repeated original control also slowed down, so host drift prevents calling
this either a demonstrated optimization or a definitive regression. Keep the
simpler original conversion. The complete reapplicable patch and candidate
executable/map are preserved in `out/handheld-042/fused-dec3n-experiment`.
The restored runtime builds and the three targeted graphics tests pass.
