# 當前驗收目標：Windows 真實標題畫面進入主選單

使用者指定：**Windows Native Sonic Free Riders 能從真實遊戲流程到達標題畫面，並可使用鍵盤或手把確認後進入主選單。任何靜態截圖、假 UI、獨立重製畫面都不算達成。**

## 完成條件

- Windows 原生執行檔使用已驗證的本機 ROM／擷取資產，從原始遊戲入口及初始化流程執行到原本標題畫面。
- 原始遊戲程式與遊戲資產經實際繪圖路徑產生畫面；開場 Logo、空白視窗、固定圖片、展示頁或手寫選單不能替代。
- 鍵盤或手把的確認輸入進入遊戲使用的輸入路徑，觸發原本標題至主選單的狀態轉換；按鍵只切換一張替代圖片不算。
- 提供可重現啟動命令、執行檔位置、來源 commit、必要本機資產／設定，並保存實際標題至主選單操作的日誌與畫面或錄影證據。畫面是執行結果的證據，不是完成品本身。
- 原生 process 的來源、啟動入口、資產讀取、繪圖提交及確認輸入／選單狀態轉換必須能追溯到同一實際執行；不以其他遊戲版本或模擬器展示冒充。

鍵盤或手把其中一種成功即可滿足這次明示條件；原本兩種操作支援方向仍保留。未連接手把時可先驗證鍵盤。

## 工作順序

本成果目標取代先前嚴格逐階段驗收的執行限制。CPU、runtime、載入、繪圖、必要音訊與輸入可以交錯處理必要依賴，所有工作均需直接服務上述目標。不提前展開其他平台移植、賽事遊玩、效能優化或與驗收無關的功能。

先定位當前入口停止點及其後續依賴。未知 kernel／指令語意以來源證據、受控測試與真實入口驗證建立實作；不能以推測性成功 stub 隱藏缺口。若缺少必要證據或資源，記錄具體阻礙與需要的下一項證據，不能將測試數、函式保留數或可編譯視窗當成成果。
