# 兩位玩家

Kinect 的骨架畫面一次帶六個位置，遊戲六個都會讀。所以要多一位玩家，
不需要多一台感測器，只要**多填一個位置**就好。

## 怎麼玩

插上第二支手把就有了，沒有別的開關。第二位玩家寫進第 1 號位置、
tracking id 為 2；身分是未註冊的客人，只有第一位才是登入的 profile
（就像有朋友站到你旁邊一起玩）。`SFR_TWO_PLAYERS=0` 可以讓遊戲永遠只看到
一位玩家，不管插了幾支手把。

出現與離開會印在 stderr：

```text
NUI_SECOND_PLAYER present=1
```

體感開著的時候，第一位玩家是攝影機看到的身體，**第一支手把**就是第二位
玩家——不必特地插到第二個孔。攝影機還沒找到人以前，第一支手把仍然頂著
第一位玩家的位置（見 [攝影機體感輸入](camera-input.md)）。

## 哪一支手把是誰

手把**一旦拿到玩家編號，插著就不會換**（[`pad_assignment`](../src/pad_assignment.h)）。
這件事需要特別處理，因為主機端的編號會動：

- Windows 會把新插上的 XInput 手把放進最小的空號，也就是 0 號。
- PlayStation 的手把 XInput 根本看不到，是另外走 HID 讀的
  （[`sony_gamepad`](../src/sony_gamepad.h)）。

以前 PlayStation 手把只是「沒有 XInput 手把時，代替第一位玩家」。於是用
PS 手把玩到一半插上第二支手把時，新手把拿到 XInput 0 號、變成第一位玩家，
原本那支就完全沒反應了——兩支手把搶同一個位置。

現在 PlayStation 手把本身就是一支手把，和 XInput 的四個插槽一起排隊：
還連著的手把保留自己的編號，新來的拿最小的空號，拔掉才把編號讓出來。
Linux 的 SDL 那邊同樣以 instance id 記住（joystick index 會隨拔插變動）。

XInput 的插槽只在偵測到有東西時才算數，而對空插槽查詢是很慢的，所以
連線狀況每 250 ms 才重數一次；已經在玩的那支則是每次都直接讀。

震動只有 XInput 的手把會動：PlayStation 的手把這裡只讀不寫。
